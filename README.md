# 한국 및 미국 증시 ETF 수익률 비교 대시보드

한국 증시(K Market)와 미국 증시(US Market)의 전 배율(1X, 2X, 3X, -1X, -2X, -3X) ETF를 비교 분석하고, 거래대금 기준 TOP 100 랭킹 및 7대 기간별 수익률(1W, 2W, 1M, 3M, 6M, 1Y, 3Y), 상세 기술적 지표, 4대 인터랙티브 시각화 차트를 제공하는 전문 웹 대시보드 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

### 1. 양대 핵심 증시 및 6대 배율 완벽 지원 (사이드바)
- **시장 선택**:
  - `K Market` (한국거래소 상장 1,168개 ETF 전수 분석)
  - `US Market` (미국 뉴욕/나스닥 상장 글로벌 메이저 143개 ETF)
- **배율 선택 (Multiplier)**:
  - `1X` (디폴트 - 정방향 1배수 기본형)
  - `2X` (레버리지 2배수)
  - `3X` (초고배율 레버리지 3배수)
  - `-1X` (인버스 숏 포지션)
  - `-2X` (곱버스 / 울트라숏 -2배수)
  - `-3X` (초고배율 인버스 -3배수)
  - `전체(All)` (전체 배율 통합 비교)
- **국내 규제 안내 배너**: 국내 자본시장법상 최대 ±2배로 제한되는 한국 시장 특성을 반영하여, K Market에서 3X/-3X 선택 시 친절한 규제 안내 및 US Market 이동 가이드 제공.

### 2. 7대 기간별 수익률 스마트 정렬 필터
- 기본 정렬: **거래대금 높은순 (디폴트)**
- 스마트 필터 정렬 기준:
  - `1W(%)`, `2W(%)`, `1M(%)`, `3M(%)`, `6M(%)`, `1Y(%)`, `3Y(%)` 수익률 높은순
  - `거래량 높은순`, `현재가 높은순`
- 검색 기능: 종목명 및 코드/티커 실시간 스마트 검색

### 3. 거래대금 기준 TOP 100 데이터 테이블
- **15개 필수 항목**:
  `순위`, `코드/티커`, `종목명`, `시장`, `배율`, `현재가`, `거래량`, `거래대금`, `1W(%)`, `2W(%)`, `1M(%)`, `3M(%)`, `6M(%)`, `1Y(%)`, `3Y(%)`
- **전일 종가 기준** 가격, 거래량, 거래대금 및 구간별 정밀 수익률 산출
- **테이블 헤더 정렬 토글**: 각 컬럼 헤더 클릭 시 오름차순/내림차순 자유로운 정렬 지원
- **단일 행 선택 연동**: 테이블의 특정 행을 클릭하면 하단 상세 영역과 실시간 즉각 동기화

### 4. 서식 적용 엑셀(.xlsx) 리포트 다운로드
- 다크 네이비 헤더(`#1E293B`), 한국 원화(₩) 및 미국 달러($) 통화 서식, 양수(빨간색)/음수(파란색) 수익률 서식, 열 너비 자동 최적화가 적용된 전문가용 엑셀 파일 원클릭 다운로드

### 5. 선택 ETF 상세 분석 및 4대 인터랙티브 차트
1. **차트 1: 주가 및 이동평균선(20일/60일/120일) & 거래량 복합 차트**
2. **차트 2: 7대 구간 수익률(1W~3Y) 한눈에 보는 바 차트**
3. **차트 3: 벤치마크 지수(코스피 200 / S&P 500) 대비 누적 상대 수익률 비교 차트**
4. **차트 4: 최대 낙폭(MDD, Drawdown) 및 리스크 분석 차트** (레버리지 상품의 음의 복리 및 변동성 잠식(Decay) 리스크 점검)
5. **전문가 종합 ETF 투자 진단 카드**: 배율 적합성, 유동성/슬리피지 평가, 모멘텀 상태 진단

### 6. 초고속 즉시 실행 및 하이브리드 캐싱
- 사전 컴파일된 `etf_master_data.csv`를 통해 앱 구동 시 **0.1초 즉시 실행**
- 사이드바 **'🔄 최신 데이터 강제 갱신'** 버튼을 통해 최신 전일 종가 및 수익률을 언제든 원클릭 백그라운드 갱신 가능

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 대시보드 실행
- **Windows**: `run_app.bat` 더블 클릭
- 또는 터미널에서:
```bash
streamlit run app.py
```
실행 후 웹 브라우저에서 `http://localhost:8501`이 자동으로 열립니다.
